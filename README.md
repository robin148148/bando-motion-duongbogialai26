# Bản Đồ Số & Motion Graphics Cầu Đường Gia Lai (Cyber-GIS)

Ứng dụng web bản đồ tương tác Cyber-GIS và đồ họa chuyển động (Motion Graphics) theo tim tuyến đường bộ tỉnh Gia Lai.

## 🚀 Tính năng chính
- **11 Tuyến đường bộ**: QL19, QL25, Đường Trường Sơn Đông (ĐTSĐ), Đường Hồ Chí Minh (ĐHCM), Tuyến tránh Pleiku, QL19D, ĐT665, ĐT662b, ĐT663, Tuyến tránh Chư Sê, ĐT668.
- **163 Điểm mốc kỹ thuật**: 115 cầu đường bộ, 26 nút giao, 22 điểm đầu/cuối tuyến.
- **Motion Graphics Tim Đường**: Mô phỏng bay dọc tim tuyến với đồng hồ điện tử LRS nhảy lý trình theo mét, kích hoạt thông tin công trình tự động.
- **Bản đồ số tra cứu GIS (163 điểm)**: Tích hợp lớp nền vệ tinh Google Hybrid, bộ lọc tuyến đường, tìm kiếm theo lý trình Km và hiển thị mặt cắt nhịp cầu.
- **Độc lập, không phụ thuộc backend**: Chạy trực tiếp trên trình duyệt máy tính và điện thoại.

## 🌐 Triển khai qua GitHub Pages
Trang web được cấu hình sẵn tệp `index.html` để kích hoạt trực tiếp tính năng GitHub Pages miễn phí từ nhánh `main`.
